# Gemma-2 Fine-Tuning for Toxic Comment Classification

[![Hugging Face Model](https://img.shields.io/badge/Hugging%20Face%20Model-%23FFD21E.svg?style=for-the-badge&logo=huggingface&logoColor=white)](https://huggingface.co/nnl26/gemma-2-toxic-classification "Перейти на Hugging Face")

Репозиторий содержит ноутбук для дообучения большой языковой модели **Google Gemma-2-2b-it** для задачи бинарной классификации токсичных комментариев на английском языке. 

Благодаря оптимизациям библиотеки **Unsloth (QLoRA)**, пайплайн обучения адаптирован под ограничения видеопамяти и работает на видеокарте **Tesla T4 (16GB)** в Google Colab.

## Особенности проекта
- **Эффективность параметров:** Заморожено >99% весов базовой модели. Обучаются только LoRA-адаптеры, **1.56%** от всех параметров.
- **Скорость и память:** Использование 4-битного квантования и динамического паддинга батчей позволило избежать ошибок нехватки памяти (OOM) и ускорило обучение.
* **Качество данных / Error Analysis:** Анализ расхождений показал, что в спорных ситуациях модель принимает более логичные решения.

## Результаты и метрики

Для улучшения качества проведен перебор порогов вероятности на валидационной выборке. Оптимальным оказался порог **0.46**, который показал лучший баланс точности и полноты.

| Метрика | Значение на тесте, Threshold = 0.46 | Комментарий |
| :--- | :---: | :--- |
| **Accuracy** | 97% | Общая доля правильных ответов модели |
| **Loss** | 0.0928 | Средняя ошибка на тестовых данных |
| **F1-Score (Clean)** | 0.9800 | Распознавание безопасного контента |
| **F1-Score (Toxic)** | 0.8300 | Сбалансированная метрика между Precision и Recall |

Разница между F1-score на валидации 0.8344 и тесте 0.8300 составляет около 0.5%, что говорит об отсутствии переобучения и хорошей обобщающей способности модели.

## Стек 
- **Base Model:** [Google Gemma-2-2b-it](https://huggingface.co/google/gemma-2-2b-it)
- **Fine-Tuning:** Unsloth, PEFT (LoRA), BitsAndBytes (4-bit quantization)
- **Frameworks:** PyTorch, Hugging Face Transformers & Datasets, Scikit-Learn
- **Hardware:** Google Colab / GPU Tesla T4 (16GB VRAM)

## Структура ноутбука
1. **Подготовка и EDA:** Анализ распределения длин комментариев, токенизация и настройка динамического паддинга `DataCollatorWithPadding`.
2. **Загрузка модели:** Инициализация квантованной Gemma-2 через `FastLanguageModel`.
3. **Настройка LoRA:** Конфигурация целевых модулей `q, k, v, o, gate, up, down_proj` с параметрами `r=32` и `alpha=64`.
4. **Обучение:** Запуск `Trainer` с косинусным планировщиком, оптимизатором `paged_adamw_8bit` и механизмом `EarlyStoppingCallback`.
5. **Валидация:** Подбор оптимального порога классификации по метрике F1.
6. **Анализ ошибок:** Исследование кейсов False Positive и False Negative.
